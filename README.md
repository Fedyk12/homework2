## Задача 1. 

Дан произвольный текст:

```
Дом, в котором мы живём, — это не просто дом. В доме живут люди, и люди эти делают дом домом. Без людей дом — просто стены, а стены без дома и без людей — уже не дом, а коробка.
```

Программа должна вывести:
- общее количество слов в тексте и количество различных (уникальных) слов;
- топ-5 самых частых слов с указанием, сколько раз каждое встретилось; при равной частоте слова
выводятся в алфавитном порядке;
- самое длинное слово текста; если таких несколько — вывести все в порядке первого появления;
- словарь вида {длина слова: сколько таких слов}, например {2: 4, 3: 9, 5: 3} — сколько в тексте слов
каждой длины

Обратите внимание: слова «Дом», «дом» и «дом.» — это
одно и то же слово, поэтому перед подсчётом текст нужно нормализовать (привести к нижнему регистру и
убрать знаки препинания).

Пример вывода:

```
Всего слов: 28, из них уникальных: 12
Топ-5 слов: дом (6), людей (3), без (2), в (2), и (2)
Самое длинное слово: живём
Слова по длинам: {2: 4, 3: 9, 5: 3}
```
